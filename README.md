# EvolveAI — Personal, Model-Agnostic, Self-Evolving AI Intelligence Platform

> "Bring your own model. Build your own intelligence. Keep your knowledge evolving."

EvolveAI allows every registered user to connect their personal AI providers and API keys (Google Gemini, OpenAI, Claude, Grok, Mistral, OpenRouter). The platform provides an independent intelligence layer for persistent memory, project context, knowledge relationships, response feedback, and continuous evolution.

---

## Key Pillars

1. **Model Independence & BYOK**: Switch models at any time while preserving memory, project decisions, and conversation continuity. Credentials encrypted with AES-GCM-256.
2. **Personal Memory Engine**: 12 structured memory categories with approval workflows and contradiction detection.
3. **Project Workspaces**: Strict contextual isolation preventing unrelated knowledge cross-contamination.
4. **Relational Knowledge Graph**: Trace connections between goals, decisions, tools, and projects.
5. **Evolution Lab**: Measurable retrieval and response quality tracking without fabricated metrics.
6. **Zero Infrastructure Cost**: Built for Cloudflare Pages, Cloudflare Workers, and Cloudflare D1 free tiers.
